# Elektro Hruška – webová prezentace

Jednostránkový statický web pro firmu **Elektro Hruška** – elektroinstalace, zabezpečovací systémy, kamerové systémy, revize a hromosvody.

## Obsah

- `index.html` – kompletní jednostránkový web (HTML + CSS + JS v jednom souboru)
- `vercel.json` – konfigurace pro Vercel hosting
- `.gitignore` – ignorované soubory

## Lokální spuštění

Stačí otevřít `index.html` v prohlížeči. Není potřeba žádný build proces ani server.

## Nasazení na Vercel

Projekt je připraven pro nasazení na [Vercel](https://vercel.com). Stačí ho propojit s GitHub repozitářem.

## Technologie

- Čisté HTML5, CSS3, vanilla JavaScript
- Google Fonts (Manrope, Outfit)
- Inline SVG ikony a logo
- Plně responzivní (mobil, tablet, desktop)
- Bez frameworků a závislostí

## Vlastnosti

- Sticky navigace s plynulým scrollováním
- Hero sekce s plovoucími kartami
- 9 detailních popisů služeb
- Sekce „Proč my" s benefity
- 4kroký proces spolupráce
- 6 zákaznických referencí
- O nás s prezentací zakladatele
- FAQ akordeon (7 otázek)
- Kontaktní formulář
- Plovoucí pohotovostní tlačítko
- Mobilní hamburger menu
